# جرّب GOLDEN ERP في المتصفح (بدون خادم)

النظام يعمل على **GitHub Codespaces**: GitHub يشغّله لكم مجانًا (ضمن الساعات المجانية الشهرية لحسابكم) ويفتحه في المتصفح. بيانات **تجريبية DEMO** فقط.

## الخطوات (من الكمبيوتر)
1. افتح صفحة المستودع على GitHub: `github.com/golden-chips/sales` وتأكد أنك على الفرع `claude/golden-erp-platform-odgb7i` (قائمة الفروع أعلى يسار قائمة الملفات).
2. اضغط الزر الأخضر **Code** ← تبويب **Codespaces** ← **Create codespace on claude/golden-erp-platform-odgb7i**.
3. انتظر: أول مرة 5–10 دقائق (يبني النظام ويجهّز البيانات). سترى نافذة شبيهة بمحرر برامج — لا تحتاج أن تفعل فيها شيئًا.
4. عند الجاهزية يفتح تبويب جديد بشاشة الدخول. إن لم يفتح: في الأسفل تبويب **PORTS** ← السطر «GOLDEN ERP (80)» ← أيقونة الكرة الأرضية 🌐.
5. ادخل بـ:
   * رمز الشركة `demo-foods` (يُطلب مرة واحدة ويتذكره الجهاز) · اسم المستخدم `owner` · كلمة المرور `Demo!Trial2026`
   * المندوب: `rep` · `Rep!Trial2026`
   * **جرّب كل دور بنفسه** — الدخول باسم المستخدم (البريد يعمل أيضًا)، وكلمة المرور `Demo!Trial2026` لكلها:

| الدور | اسم المستخدم | ماذا تجرب |
|---|---|---|
| المدير العام (كل الصلاحيات) | `gm` | الترحيل والاعتمادات وكل الشاشات |
| مدير المبيعات | `sales` | عروض الأسعار، أوامر البيع، الفواتير، العملاء المحتملون |
| المدير المالي | `finance` | اعتماد أمر الشراء المعلّق، اعتماد الرواتب، الأصول |
| المحاسب | `accountant` | القيود وميزان المراجعة والسندات |
| أمين المخزن | `warehouse` | أوامر الشراء والاستلام والمخزون |
| مدير الإنتاج / الجودة | `production` / `quality` | أوامر الإنتاج، الفحوصات والتتبع |
| الكاشير / مشرف الصالة | `cashier` / `possup` | شاشة البيع (الوردية مفتوحة) والإغلاق |
| الموارد البشرية | `hr` | الموظفون والحضور ومسير الشهر الماضي |
| الصيانة / خدمة العملاء / المشاريع | `maintenance` / `service` / `projects` | أوامر الصيانة، الشكاوى، مشروع الخط 3 |

البيانات التجريبية تشمل: فواتير آخر 45 يومًا، عرض سعر وأمر بيع وأمري شراء (أحدهما بانتظار اعتماد المدير المالي)، وردية كاشير مفتوحة، أمر إنتاج مكتمل بفحص جودة، أصلين وخطة صيانة وبلاغ عطل، حملة وعملاء محتملين وفرص وتذاكر، مستندين، مشروعًا بمهامه، 4 موظفين بحضور الشهر الماضي ومسير رواتب معتمد. كلها تحمل كلمة DEMO وليست بيانات حقيقية.

## ملاحظات
* الرابط خاص بكم (يتطلب تسجيل دخولكم في GitHub).
* لإيقافه: github.com/codespaces ← «Stop». يتوقف تلقائيًا بعد 30 دقيقة دون استخدام، وبياناته التجريبية تبقى حتى تحذفه.
* إذا ظهرت رسالة أن Codespaces غير مفعّل للمنظمة: مالك منظمة golden-chips يفعّله من Settings ← Codespaces، أو أخبرونا.
* هذا للتجربة فقط؛ التشغيل الحقيقي ببيانات الشركة على خادم بحسب `DEPLOYMENT_AR.md`.
