# الفترة التجريبية وتهيئة العملاء

## رحلة العميل الجديد
1. **صفحة التسجيل** `/signup` (رابط «جرّب مجانًا» في صفحة الدخول): اسم الشركة، رمز الدخول (يُفحص توفره فورًا)، الاسم، البريد، الهاتف، كلمة مرور قوية، والموافقة على الشروط.
2. خلال ثانية: تُنشأ الشركة على **باقة التجربة** (اليوم: «التصنيع» 14 يومًا — يغيّرها مالك المنصة)، مع **دليل حسابات وسنة مالية جاهزين**، ويدخل المالك مباشرة. كل ذلك في معاملة واحدة.
3. **شريط علوي** يعرض الأيام المتبقية وزر **«اطلب الاشتراك»** (اختيار الباقة والدفع الشهري/السنوي وهاتف للتواصل).
4. **مالك المنصة** يرى الطلبات في لوحة المنصة ← «تفعيل» (يغيّر الباقة ويصدر فاتورة الاشتراك) أو «رفض».
5. **إن لم يشترك**: عند نهاية التجربة يصبح الحساب «متأخرًا» (يعمل مع تحذير أحمر) لمدة مهلة السماح، ثم **يُعلّق** وتُلغى جلساته. البيانات تبقى، وإعادة التفعيل تعيده كما كان.

## تحميل بيانات العميل
**«استيراد من Excel»**: قالب لكل نوع ← معاينة تكشف كل خطأ بالصف والعمود ← استيراد كامل أو لا شيء.
الترتيب: الأصناف ← العملاء والموردون ← أرصدة المخزون ← أرصدة الحسابات. الأرصدة الافتتاحية تُنشأ مسودات يرحّلها محاسب آخر.

## الحماية
* التسجيل محدود بـ 5 محاولات في الساعة لكل عنوان IP (`SIGNUP_RATE_LIMIT_PER_HOUR`).
* **غير منفّذ بعد**: تأكيد البريد/الهاتف برمز، وحماية CAPTCHA — مطلوبان قبل فتح التسجيل للعامة على نطاق واسع.
