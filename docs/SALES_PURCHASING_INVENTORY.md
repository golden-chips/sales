# المبيعات والمشتريات والمخزون — دليل سير العمل (المرحلة 2b)

كل مستند يمر بـ **مسودة ← ترحيل**. الترحيل ينفّذ حركة المخزون والقيد المحاسبي **في معاملة واحدة**: إما أن ينجح كاملًا أو لا يحدث شيء. يُطبّق فصل المهام: من أنشأ المستند لا يرحّله (إعداد قابل للتعطيل).

## البيانات الأساسية
| الشاشة | ملاحظات |
|---|---|
| الأصناف | النوع: خام / تعبئة / نصف مصنع / تام / خدمة؛ وحدة أساسية + وحدات بديلة بمعامل (كرتونة = 24 كيس)؛ تتبع التشغيلات والصلاحية؛ مدة الصلاحية تحسب تاريخ الانتهاء تلقائيًا من تاريخ الإنتاج؛ حد إعادة الطلب |
| العملاء | حد ائتمان (فارغ = بلا حد)، مدة سداد تحدد تاريخ الاستحقاق، أسعار خاصة لكل صنف (`PUT /customers/:id/prices`) |
| الموردون | مدة السداد تحدد استحقاق فاتورة المورد |
| المخازن | النوع يحدد السلوك: `quarantine`/`damaged` **غير قابلة للبيع بقيد في قاعدة البيانات**؛ `van` لسيارات التوزيع |

## التكلفة
**متوسط مرجح لكل (مخزن، صنف)**. الكمية والقيمة في `stock_balances` لا يمكن أن تصبح سالبة (قيد CHECK). الحسابات كلها بأرقام `numeric` في PostgreSQL. سجل الحركات `stock_moves` غير قابل للتعديل أو الحذف، ويربط كل حركة بسطر المستند الذي أنشأها.

## الدورات
| المستند | عند الترحيل — المخزون | عند الترحيل — القيد (أدوار الحسابات) |
|---|---|---|
| **رصيد افتتاحي** | دخول بتكلفة محددة (+ تشغيلة) | مدين مخزون / دائن `opening_balance` |
| **تسوية جرد** | ± | مخزون مقابل `inventory_adjustment` |
| **إتلاف** | خروج بالمتوسط | مدين `production_scrap` / دائن مخزون |
| **تحويل** | خروج ثم دخول بنفس القيمة ونفس التشغيلات | فقط إن اختلف حساب المخزون (مثل مخزن ← سيارة) |
| **إفراج من الحجر** | من مخزن الحجر فقط، **بصلاحية الجودة** (`inventory.quarantine.release`) | مدين مخزون الوجهة / دائن `inventory_quarantine` |
| **إذن استلام** | دخول بالتكلفة الفعلية؛ إنشاء التشغيلة وربطها بالمورد؛ التشغيلة إلزامية للأصناف المتتبعة | مدين مخزون / دائن `grni` |
| **فاتورة مورد** | — | مدين `grni` / دائن `ap`؛ لا تتجاوز قيمة الاستلام غير المفوترة؛ رقم فاتورة المورد لا يتكرر |
| **سند صرف لمورد** | — | مدين `ap` / دائن نقدية/مصرف؛ لا يتجاوز المتبقي |
| **فاتورة مبيعات** | خروج **FEFO** (الأقرب انتهاءً أولًا) **مع استبعاد التشغيلات المنتهية**؛ بيع تشغيلة منتهية يدويًا مرفوض | مدين `ar` أو `cash_main` / دائن `sales_revenue` (إجمالي)، مدين `sales_discounts`، دائن `tax_payable`؛ مدين `cogs` / دائن مخزون |
| **مرتجع مبيعات** | **إلى مخزن حجر فقط**، لنفس التشغيلات التي خرجت منها، بتكلفتها الأصلية؛ لا يتجاوز المباع | مدين `sales_returns` / دائن `ar` (أو نقدية)؛ مدين `inventory_quarantine` / دائن `cogs` |
| **سند قبض** | — | مدين نقدية/مصرف/عهدة مندوب / دائن `ar`؛ يوزَّع على أقدم الفواتير (FIFO)، والزائد دائن `customer_advances` |

**حد الائتمان** يُفحص عند ترحيل الفاتورة الآجلة: (الرصيد المفتوح + الفاتورة) ≤ الحد.

## التقارير
* أرصدة المخزون بالمتوسط والقيمة والتشغيلات وأيام الصلاحية، مع **مطابقة قيمة المخزون مع الأستاذ العام**.
* بطاقة الصنف: كل حركة برصيد جارٍ ورابط للمستند.
* **تتبع التشغيلة**: المورد، كل الحركات، والعملاء الذين استلموها (مباع/مرتجع/بالسوق) — أساس الاستدعاء.
* أعمار الديون (غير مستحق، 1–30، 31–60، 61–90، +90)، كشف حساب العميل برصيد جارٍ، تحليل المبيعات والربحية حسب الصنف والعميل (صافي المرتجعات).

## غير منفّذ بعد في هذه الدورة
أوامر البيع وحجز الكميات، عروض الأسعار، طلبات الشراء وأوامر الشراء و RFQ والموافقات، فروق أسعار فاتورة المورد، مصاريف الشحن (Landed Cost)، الأرقام التسلسلية، المواقع داخل المخزن، الرد النقدي لمرتجع فاتورة آجلة مسددة، إشعارات الخصم/الإضافة، قوائم الأسعار المتعددة. (انظر KNOWN_ISSUES.md)
