# علاقات العملاء، المستندات والاعتمادات، المشاريع (Phase 6d)

## علاقات العملاء (CRM)
| الوظيفة | السلوك |
|---|---|
| الحملات | قناة (ميداني، سوشيال، واتساب، معرض…)، ميزانية، وعدد العملاء المحتملين والمتحوّلين لكل حملة |
| العملاء المحتملون | مصدر وحملة ومسؤول؛ **منع التكرار بالهاتف**؛ مراحل (جديد ← تم التواصل ← مؤهل)؛ الفقد بسبب إلزامي؛ **التحويل إلى عميل حقيقي** ينشئ بطاقة العميل (بصلاحية إدارة العملاء) وينقل فرصه إليه |
| الفرص البيعية | مسار مرئي: استكشاف ← عرض سعر ← تفاوض ← ربح/خسارة؛ الاحتمال يتبع المرحلة؛ القيمة المرجّحة لكل مرحلة ونسبة الربح؛ الفرصة المغلقة لا تتحرك |
| الأنشطة | اتصال، اجتماع، زيارة، مهمة، بريد، ملاحظة — مرتبطة بعميل/فرصة/تذكرة؛ «متابعاتي» مع إبراز المتأخر |
| خدمة العملاء | تذاكر (شكوى، استفسار، خدمة، اقتراح) برقم TK، **وقت استجابة حسب الأولوية** (حرج 4 ساعات، عالٍ 24، عادي 3 أيام، منخفض 7)، الحل إلزامي للإغلاق، **تقييم رضا العميل 1–5 بعد الحل فقط** |
| شكوى على منتج | ربط التذكرة بالتشغيلة، وخيار **فتح حالة عدم مطابقة لدى الجودة** تلقائيًا (قرار إيقاف التشغيلة يبقى للجودة) |
| مؤشرات الخدمة | المفتوح، تجاوزات وقت الاستجابة، متوسط زمن الحل، متوسط الرضا |

## المستندات والاعتمادات
* رفع مستند (PDF، صور، Word، Excel، نص — حتى 10 ميجابايت؛ الملفات التنفيذية مرفوضة) وربطه بأي سجل (عميل، مورد، أصل، موظف، تشغيلة…).
* **الإصدارات لا تُعدّل ولا تُحذف** (قيد في قاعدة البيانات)، ولكل إصدار بصمة SHA-256؛ المستند يُؤرشف ولا يُحذف.
* **مستندات سرية** (عقود، رواتب) لا تظهر في البحث ولا تُفتح إلا لصاحب صلاحية `documents.restricted.view`.
* تاريخ انتهاء للتراخيص والشهادات والعقود، وقائمة «تنتهي خلال 60 يومًا».
* البحث بالعنوان والوسوم واسم الملف. كل تنزيل يُسجّل في سجل التدقيق.
* **الاعتماد الإلكتروني متعدد الخطوات**: خطوات متتالية حسب الدور أو مستخدم محدد؛ مقدم الطلب لا يعتمد طلبه؛ الرفض بسبب إلزامي؛ **كل قرار يسجل بصمة الملف المعتمد بالضبط** والوقت والشخص. صندوق «اعتماداتي» لكل مستخدم.

## المشاريع
* كل مشروع يُنشأ له **مركز تكلفة** تلقائيًا؛ أي قيد أو فاتورة على مركز التكلفة هذا يظهر كتكلفة فعلية، فالميزانية مقابل الفعلي **تطابق الأستاذ العام دائمًا**.
* المهام بمسؤول وتاريخ وساعات تقديرية؛ نسبة إنجاز المشروع موزونة بالساعات؛ المهام المتأخرة؛ المسؤول يحدّث إنجاز مهمته فقط، ومدير المشروع كل شيء.
* تنبيه تجاوز الميزانية، وقائمة «مهامي».

## الأدوار الجديدة
**خدمة العملاء** (التذاكر فقط)، **مدير مشاريع**. المدير المالي ومدير الموارد البشرية: كل صلاحيات المستندات بما فيها السرية؛ مدير المبيعات والجودة: المستندات العادية وطلب الاعتماد.

## حدود معروفة
* التوقيع الإلكتروني القانوني (شهادة رقمية من جهة معتمدة) غير متاح — الاعتماد الحالي سجل تدقيق بالبصمة والوقت والمستخدم. (K39)
* الملفات تُخزّن داخل قاعدة البيانات (مناسب للتجربة وحجم متوسط)؛ مع حجم كبير تُنقل لتخزين كائنات. (K40)
* بعض المدخلات تستخدم نافذة المتصفح البسيطة (سبب الفقد، الحل، التقييم) — تُستبدل بنوافذ مخصصة (ضمن K17).
* لا يوجد مخطط Gantt ولا تبعيات بين المهام ولا تسجيل ساعات فعلية على المهام. (K41)
