# الأصول الثابتة والصيانة — Fixed Assets & Maintenance (Phase 6a)

## ما المنفّذ والمختبر
| الوظيفة | السلوك | القيد المحاسبي |
|---|---|---|
| فئات الأصول | كل فئة تحدد طريقة الإهلاك والعمر الإنتاجي ونسبة الخردة و**حسابات صريحة**: الأصل، مجمع الإهلاك، مصروف الإهلاك، مصروف الصيانة. يُتحقق من أنواع الحسابات (أصل/مصروف) | — |
| بطاقة الأصل (مسودة) | آلة/معدة/مركبة/مبنى/أثاث/أجهزة؛ رقم تسلسلي، موقع، فرع، خط إنتاج، مخزن (للسيارات). القيم الافتراضية من الفئة | — |
| الرسملة | مستخدم آخر غير منشئ البطاقة (فصل المهام). الحساب الدائن يختاره المستخدم (بنك، خزينة، أرصدة افتتاحية…)؛ **حسابات الذمم (عملاء/موردين) مرفوضة** حتى لا يختل الأستاذ المساعد | مدين الأصل بالتكلفة / دائن مجمع الإهلاك المرحّل (للأصول القديمة) / دائن الحساب المختار بالباقي |
| أصول مستخدمة قبل النظام | يُدخل الإهلاك المتراكم والأشهر المستهلكة، ويُكمل النظام الإهلاك على الأشهر المتبقية | كما أعلاه |
| الإهلاك الشهري | دورة لكل شهر: مستخدم يُعدّها وآخر يرحّلها. **متتالية**: لا تخطي شهر ولا تكرار شهر (قيد فريد على الأصل+الشهر). يبدأ الإهلاك في **الشهر التالي** لبدء الاستخدام. القسط الثابت يوزّع المتبقي على الأشهر المتبقية فينتهي الأصل بالضبط عند قيمة الخردة بلا فروق تقريب. المتناقص المضاعف يتحول للقسط الثابت عندما يصبح أكبر | مدين مصروف الإهلاك / دائن مجمع الإهلاك، لكل فئة |
| حماية الدورة | إذا تغير أصل بعد إعداد الدورة يُرفض الترحيل ويُطلب إعادة الإعداد | — |
| الاستبعاد/البيع | يُشترط عدم وجود دورة مسودة تخص الأصل وعدم ترحيل إهلاك لشهر الاستبعاد أو بعده | مدين مجمع الإهلاك + مدين المتحصلات / دائن تكلفة الأصل؛ الفرق خسارة (مدين) أو ربح (دائن) على الحساب المختار |
| تجميد البيانات | بعد الرسملة تُجمّد الحقول المالية (تكلفة، عمر، طريقة، تواريخ…) على مستوى قاعدة البيانات؛ المستبعد لا يتغير إلا الموقع والملاحظات؛ لا حذف لأصل مرسمل | — |
| خطط الصيانة الوقائية | كل N يوم مع قائمة فحص. «توليد المستحق» ينشئ أمرًا واحدًا لكل خطة مستحقة (لا يتكرر — قيد فريد على أمر مفتوح لكل خطة). إقفال الأمر يحرّك الاستحقاق التالي = تاريخ الإنجاز + الفترة | — |
| بلاغ عطل | أمر صيانة تصحيحية بأولوية (حرج = خط متوقف) ورمز عطل | — |
| إقفال أمر الصيانة | صرف قطع الغيار من المخزن بالمتوسط المرجح (لا يُسمح بمخزن الحجر)، تكلفة خارجية (فني/ورشة)، مدة التوقف، ما تم إنجازه. نقص المخزون يُلغي العملية كاملة ويبقى الأمر مفتوحًا | مدين مصروف الصيانة / دائن المخزون (قطع الغيار) / دائن حساب الدفع (التكلفة الخارجية) |
| الاعتمادية والتكلفة | لكل أصل: عدد الأعطال، الوقائية المنفذة، ساعات التوقف، متوسط الأيام بين الأعطال (MTBF)، تكلفة الصيانة، الإهلاك | — |
| سجل عمر الأصل | الرسملة + كل شهر إهلاك + كل أمر صيانة + الاستبعاد | — |

## الصلاحيات والأدوار
* `assets.register.view/manage` (بطاقات مسودة)، `assets.register.capitalize` (حساسة)، `assets.register.dispose` (حساسة)
* `assets.depreciation.prepare`، `assets.depreciation.post` (حساسة)
* `assets.maintenance.view/manage/complete`
* المدير المالي: السجل والرسملة والإهلاك والاستبعاد. مدير الإنتاج: الصيانة. دوران جديدان: **مدير الصيانة** و**فني صيانة** (لا يرسملان ولا يهلكان ولا يستبعدان).

## قرارات وحدود معروفة
* شراء أصل من مورد بفاتورة مورد (سطر أصل في فاتورة المورد) غير منفّذ بعد: الرسملة اليوم تكون مقابل بنك/خزينة/أرصدة افتتاحية أو حساب التزام غير الذمم. (K31)
* إعادة التقييم، الانخفاض في القيمة، الإهلاك بوحدات الإنتاج (ساعات تشغيل)، تقسيم/دمج الأصول، نقل الأصل بين الشركات: غير منفّذة. (K32)
* تكلفة عمالة الصيانة الداخلية لا تُرحَّل من أمر الصيانة (هي ضمن الرواتب أصلًا).
* إعادة مزامنة الأدوار للمستأجرين الحاليين: `npm run roles:sync` بعد الترقية.
