# نقاط البيع — Point of Sale (Phase 6b)

## الفكرة الأساسية
**عملية البيع في نقطة البيع هي فاتورة مبيعات حقيقية** تُنشأ وتُرحّل في معاملة واحدة، فتعمل عليها تلقائيًا كل وظائف المبيعات الموجودة: صرف المخزون FEFO مع استبعاد التشغيلات المنتهية/الموقوفة، تكلفة البضاعة، الإيرادات والخصومات، كشف حساب العميل، أعمار الديون، تحليل المبيعات، تتبع التشغيلة والاستدعاء. لا يوجد مسار مالي موازٍ.

## الإعداد (نقطة البيع)
| الحقل | القاعدة |
|---|---|
| مخزن البيع | يجب أن يكون صالحًا للبيع |
| مخزن المرتجعات | يجب أن يكون **حجر/فحص** — المرتجع الغذائي لا يعود للرف قبل قرار الجودة |
| العميل النقدي | يُستخدم عند عدم اختيار عميل |
| حساب الدرج / الخزينة الرئيسية / البطاقات / العجز والزيادة | حسابات صريحة؛ حسابات الذمم مرفوضة |
| حد الخصم | خصم الكاشير لكل سطر حتى هذا الحد؛ ما فوقه يتطلب صلاحية `pos.sales.discount_override` |
| رأس وتذييل الإيصال | يظهران في الإيصال المطبوع |

## دورة الوردية والقيود
| الحدث | القيد |
|---|---|
| فتح الوردية (عهدة) | مدين الدرج / دائن الخزينة الرئيسية |
| بيع | مدين الدرج (النقدي) + مدين حساب البطاقات + مدين ذمم العميل (الآجل) / دائن الإيرادات، مدين الخصومات؛ مدين تكلفة المبيعات / دائن المخزون |
| مرتجع | مدين مردودات المبيعات / دائن الدرج أو البطاقات (أو ذمم العميل للآجل)؛ مدين مخزون الحجر / دائن تكلفة المبيعات |
| سحب نقدية للخزينة (مشرف) | مدين الخزينة / دائن الدرج |
| الإقفال (Z) | مدين الخزينة بالمعدود / دائن الدرج **بالمتوقع**؛ الفرق إلى حساب العجز والزيادة. **حساب الدرج يعود إلى صفر بعد كل وردية** |

النقدية المتوقعة = العهدة + النقدي المبيع − النقدي المردود − السحوبات.

## الضوابط
* وردية مفتوحة واحدة لكل نقطة بيع ولكل كاشير (قيد قاعدة بيانات).
* الكاشير يبيع في ورديته فقط؛ المشرف يرى كل الورديات ويسحب النقدية ويغلق أي وردية.
* **منع البيع المكرر:** كل عملية تحمل معرّفًا من الجهاز (clientId)؛ إعادة الإرسال (ضعف الشبكة، نقر مزدوج) تعيد نفس الفاتورة ولا تبيع مرتين.
* مجموع الدفع يجب أن يساوي الإجمالي وإلا لا يُرحّل شيء.
* البيع الآجل يتطلب صلاحية وعميلًا مسجّلًا، ويخضع لحد الائتمان على الجزء الآجل فقط.
* المرتجع بصلاحية مستقلة، لا يتجاوز المباع، والرد النقدي لا يتجاوز نقدية الدرج.
* الوردية المغلقة وحركاتها لا تُعدّل ولا تُحذف (حركات الدفع للإضافة فقط).
* الباركود: للوحدة الأساسية (كيس) أو لوحدة التعبئة (كرتونة)؛ لا يتكرر الباركود داخل الشركة.

## الشاشة
* شاشة بيع: مسح الباركود أو البحث، بطاقات الأصناف بالكمية المتاحة الصالحة للبيع، السلة بالخصم، الدفع (نقدي/بطاقة/آجل) مع حساب الباقي، إيصال 80 مم يُطبع من المتصفح على أي طابعة متصلة بالجهاز، تقرير X، الإقفال بالعد وتقرير Z، المرتجع برقم الفاتورة.
* الورديات (الإدارة): كل الورديات بالفروقات، وإعداد نقاط البيع.

## الأدوار
* **كاشير**: فتح/إغلاق ورديته والبيع فقط.
* **مشرف نقاط البيع**: المرتجعات، الآجل، تجاوز الخصم، سحب النقدية، إغلاق أي وردية — بدون إعداد الحسابات.
* المدير المالي: إعداد نقاط البيع ومتابعة الورديات.

## حدود معروفة
* نقطة البيع تحتاج اتصالًا بالخادم لإتمام البيع (منع التكرار مضمون عند إعادة المحاولة، لكن لا يوجد طابور بيع دون اتصال كما في تطبيق المناديب). (K33)
* لا تكامل مباشر مع أجهزة الدفع بالبطاقة (POS terminals) ولا درج نقدية آلي؛ المبلغ يُدخل يدويًا. الطباعة عبر طابعة النظام. (K34)
* العروض الترويجية (اشترِ 2 واحصل على 1)، نقاط الولاء، بطاقات الهدايا: غير منفّذة. (K35)
