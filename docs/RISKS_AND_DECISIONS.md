# المخاطر والقرارات التي تحتاج اعتمادكم

## قرارات مطلوبة منكم

| # | القرار | توصيتي | ما يترتب عليه |
|---|---|---|---|
| D1 | **المعمارية والتقنيات** (Modular Monolith، TypeScript، PostgreSQL، RLS) | اعتماد — مُنفّذة ومختبرة في المرحلة 1 | تغييرها لاحقًا مكلف |
| D2 | **مصير «سيلا»** (النظام المحاسبي الحالي) | تشغيل متوازٍ لشهر أو شهرين ثم اعتماد GOLDEN ERP كنظام محاسبي وحيد | يلغي الإدخال اليدوي المزدوج؛ يتطلب اعتماد دليل الحسابات والأرصدة الافتتاحية |
| D3 | **دليل الحسابات** | محاسب الشركة يراجع القالب المقترح (83 حسابًا) ويعدّله قبل أي ترحيل حقيقي | لا تُدخل أرصدة افتتاحية قبل الاعتماد |
| D4 | **أسعار الباقات** | الأسعار حاليًا 0 (عناصر نائبة) — تحتاج تسعيركم | لا تُصدر فواتير اشتراك حقيقية قبل ذلك |
| D5 | **الاستضافة** | خادم VPS أو سحابة إقليمية (مثلًا أوروبا القريبة) مع PostgreSQL مُدار ونسخ احتياطي PITR | يؤثر على زمن الاستجابة والتكلفة وسيادة البيانات |
| D6 | **تطبيق المندوب** | الإبقاء على تطبيق Expo الحالي وربطه بالـ API الجديد بدل إعادة كتابته | توفير أشهر من العمل |
| D7 | **الضرائب والرسوم في ليبيا** | تُبنى كقواعد قابلة للتهيئة؛ لا أفترض أي نسبة قبل تأكيد محاسبكم | — |
| D8 | **قواعد الرواتب والاستقطاعات** (الضمان الاجتماعي، الضرائب على الدخل) | قابلة للتهيئة لكل دولة؛ تحتاج النسب المعتمدة من قسم الموارد البشرية/المحاسب | — |
| D9 | **فصل المهام** مفعّل افتراضيًا (المُنشئ لا يرحّل قيده) | الإبقاء مفعّلًا؛ يمكن لكل شركة تعطيله من الإعدادات | الشركات الصغيرة ذات المحاسب الواحد قد تحتاج تعطيله |
| D10 | إن كان مشروع **«حضوري»** شيئًا آخر غير `hr-system` | إتاحته للفحص | — |

## سجل المخاطر

| الخطر | الاحتمال | الأثر | التخفيف |
|---|---|---|---|
| اتساع النطاق (18 وحدة) | عالٍ | عالٍ | تسليم مرحلي، كل مرحلة قابلة للاستخدام وحدها، تعريف إنجاز صارم |
| ترحيل بيانات Firestore بجودة متفاوتة | متوسط | عالٍ | سكربتات ترحيل مع تقارير مطابقة، تشغيل متوازٍ، لا ترحيل قبل الاعتماد |
| اختلاف أرقام بين النظام القديم والجديد (تقريب خانتين مقابل 3) | متوسط | متوسط | مطابقة يومية أثناء التشغيل المتوازي؛ التحقق من وجود أسعار بثلاث خانات |
| مقاومة المستخدمين للتغيير | متوسط | متوسط | الإبقاء على تطبيق المندوب المألوف، تدريب، واجهة عربية بسيطة |
| أمن بيانات متعدد المستأجرين | منخفض (مع RLS) | حرج | RLS إجباري + اختبارات عزل في كل تشغيل + مراجعات أمنية دورية |
| الاعتماد على مزود واحد للواتساب (Meta) | منخفض | متوسط | طبقة إشعارات مجردة تسمح بقنوات بديلة (SMS، بريد) |
