# دراسة مرجعية — مقارنة أنظمة ERP العالمية

> **منهجية وحدود:** هذه المقارنة مبنية على المعرفة العامة الموثّقة لهذه المنتجات (وثائقها الرسمية وأدلتها المنشورة حتى 2026) وليست نتيجة اختبار عملي لكل منتج في هذه الجلسة. لم يُنسخ أي كود أو تصميم أو ملكية فكرية؛ المستفاد هو **أفضل الممارسات** فقط. يُنصح بمراجعة نقاط الأسعار والترخيص مباشرة مع المورّدين قبل أي قرار تجاري، لأنها تتغير باستمرار.

## 2. نقاط القوة التي نتعلم منها

- **SAP — Universal Journal:** جدول قيود واحد هو مصدر الحقيقة لكل التقارير المالية والإدارية. *طُبّق:* `journal_lines` هو المصدر الوحيد لميزان المراجعة ودفتر الأستاذ والقوائم المالية.
- **SAP — Document Principle:** لا ترحيل بلا مستند، ولا تعديل بعد الترحيل، والتصحيح بعكس. *طُبّق* بقيود Triggers في قاعدة البيانات.
- **NetSuite — Multi-tenant أصلي:** نسخة واحدة من الكود لكل العملاء، والترقية مستمرة. *طُبّق:* قاعدة مشتركة مع RLS بدل قاعدة لكل عميل.
- **Dynamics — الأبعاد المالية:** مراكز تكلفة ومشاريع كأبعاد على سطر القيد. *طُبّق جزئيًا:* `cost_center_id` على السطر + `requires_cost_center` على الحساب.
- **Odoo — بساطة الواجهة وتكامل الوحدات:** كل حركة مخزون تولّد قيدها تلقائيًا. *مُعتمد كتصميم:* عقد `postFromSource` لكل الوحدات.
- **ERPNext — DocType workflow:** حالات Draft → Submitted → Cancelled (بقيد عكسي). *طُبّق* في القيود: مسودة → مرحّل → معكوس.

## 3. نقاط الضعف الشائعة (فرص التميّز)

1. **تكلفة وتعقيد التنفيذ** (SAP/Dynamics F&O) — غير مناسبة لمصنع أغذية متوسط في ليبيا.
2. **المبيعات الميدانية (Van Sales) ليست أصلية** في أي منها — تحتاج إضافات طرف ثالث وتكاملًا هشًا.
3. **التوطين الليبي ضعيف** (LYD 3 خانات، الفوترة العربية، واتساب كقناة أساسية للعملاء، التحويلات المصرفية المعلّقة).
4. **الاعتماد على Odoo/ERPNext** يتطلب خبرة Python/Frappe غير متوفرة محليًا بسهولة، وعزل المستأجرين فيهما بقاعدة/موقع لكل عميل يرفع تكلفة التشغيل.

## 4. ما يميز GOLDEN ERP

| الميزة | لماذا تهم |
|---|---|
| عزل المستأجرين بـ RLS إجباري + مفاتيح خارجية مركبة | حتى خطأ برمجي (نسيان WHERE) لا يكشف بيانات عميل لآخر — مُختبر |
| سلامة محاسبية على مستوى قاعدة البيانات | لا يمكن ترحيل قيد غير متوازن أو تعديل قيد مرحّل حتى بتجاوز الواجهة — مُختبر |
| Van Sales أصلي مُجرّب ميدانيًا (من نظام الشركة) | ميزة غير متوفرة جاهزة عند المنافسين |
| ZKTeco + رواتب + قيد محاسبي | حلقة كاملة من البصمة إلى القيد |
| تتبع واستدعاء غذائي أصلي | متطلب تنظيمي وتجاري للصناعات الغذائية |
| عربي أولًا + واتساب كقناة | يناسب السوق المستهدف |
